## 1. 连接管理

### 新建连接

1. 点击左侧栏顶部「**+ 新建连接**」按钮
2. 填写：
   - **连接名称**：自定义，用于在侧栏展示（如「本地开发」「测试库」）
   - **主机 / 端口 / 用户名 / 密码**：MySQL 服务器信息，端口默认 `3306`
   - **默认数据库**：可选，连接后默认使用的库
3. 点击「连接测试」验证，通过后「保存」

### 记住密码

- **勾选**「记住密码」：密码保存在本机浏览器 `localStorage` 中（明文），下次打开免输入
- **不勾选**：密码仅本次会话有效，刷新页面后需重新填写
- ⚠️ 请勿在公共电脑上勾选记住密码

### 高级选项

桥接地址通常**无需填写**：

- **Web 模式**：留空时自动使用当前页面同源的内置桥接器 `ws://{host}/__mysql_bridge`（随 `npm run dev` 启动）
- **Chrome 插件模式**：留空时自动连接本机独立桥接器 `ws://localhost:5189/__mysql_bridge`（需先运行 `npm run bridge`）

仅当桥接器与页面不同源时（例如自建了独立桥接服务）才需要手动填写，格式必须以 `ws://` 或 `wss://` 开头。

### 连接操作

在左侧树的**连接节点**上右键：

| 菜单项 | 说明 |
| --- | --- |
| 打开连接 / 断开连接 | 建立 or 断开 WebSocket 桥接会话 |
| 刷新元数据 | 重新拉取 Schema / 表 / 视图列表 |
| 新建查询 | 用该连接打开一个新的查询标签页 |
| 新建 Schema… | 弹窗创建数据库（Schema），确认后执行 `CREATE DATABASE` 并自动刷新列表（仅已连接时可用） |
| 编辑连接 | 修改连接信息 |
| 删除连接 | 删除（红色危险项） |

## 2. 浏览数据库

左侧树为三级结构：**连接 → Schema（数据库）→ 表 / 视图**。

- **过滤**：顶部搜索框可按表名实时过滤当前 Schema 的表
- **新建 Schema（数据库）**：连接节点右键「新建 Schema…」，或 Schema 列表底部的「＋ 新建 Schema」入口。弹窗内填写名称（仅字母 / 数字 / 下划线 / `$`，上限 64 字符）、选择字符集与排序规则（按服务器大版本预选默认值，切换字符集时排序规则自动联动）、勾选 `IF NOT EXISTS`；底部实时预览将执行的 `CREATE DATABASE` 语句。创建成功后左侧树与顶部 Schema 下拉自动刷新。演示库为只读数据集，请在真实 MySQL 连接上使用
- **Schema 右键**：
  - 设为活动 Schema（当前查询标签页使用的库）
  - 在此新建查询
  - 刷新表
  - 复制名称
- **表右键**：

| 菜单项 | 说明 |
| --- | --- |
| 复制表名 / 复制全限定表名 | 复制 `table` 或 `schema`.`table` |
| 查看 DDL | 弹窗展示 `SHOW CREATE TABLE` 结果（语法高亮，可复制 / 下载） |
| 最近 10 条记录 | 自动生成并执行 `SELECT * ... ORDER BY 主键/自然序 DESC LIMIT 10` |
| 查看前 100 行 | 执行 `SELECT * ... LIMIT 100` |
| 导出 SQL（DDL + 数据）… | 打开导出弹窗，见[导出](#7-导出) |
| 导出 CSV | 直接导出表数据为 CSV 文件 |
| 在新标签页查询 | 新开一个查询标签页 |

## 3. 执行 SQL

### 多标签页

- 顶部「+」或 **⌘/Ctrl + T** 新建查询标签页；双击标签名可重命名
- 每个标签页独立记忆：使用的连接、活动 Schema、SQL 内容、执行结果
- 标签页上的 **●** 表示有未保存的脚本修改

### 编写与运行

- 编辑器基于 CodeMirror 6：SQL 语法高亮、表名/关键字补全、多光标、搜索（⌘/Ctrl + F）
- 点击「**运行**」按钮或 **⌘/Ctrl + Enter** 执行：
  - **选中了部分语句** → 只运行选中的片段
  - 未选中 → 运行编辑器全部内容（多条语句按顺序执行）
- 「**美化**」按钮可一键美化 SQL（按分号切分多语句逐条格式化）
- **自动 LIMIT 保护**：运行查询类语句（SELECT 等）时，若未手写 `LIMIT`，会按编辑器右上角「行数上限」自动附加，页脚有「已自动附加 LIMIT」提示；已含 `LIMIT` 的语句不重复添加
- 运行中按钮变为「运行中…」，可继续编辑其他标签页

### 连接与 Schema

编辑器工具条上有两个下拉框：

- **连接**：当前标签页使用的数据库连接（可随时切换）
- **Schema**：活动库。未在 SQL 中写库名时，语句默认在该库执行（也可显式写 `schema.table`）

## 4. 结果面板

执行 SQL 后，底部结果区展示结果。

### 结果页签

- 每次执行生成一个结果页签，标签显示语句摘要与行数（失败显示「失败」）
- **鼠标悬停页签，点右侧 ×** 可关闭该页签
- **页签右键菜单**：复制 CSV / 复制 INSERT / 下载 CSV / 下载 INSERT / 关闭 / 关闭其他标签页 / 关闭全部
- 页签栏最右的「**清空结果**」一键清空当前标签页的所有结果
- 「**消息**」页签：汇总每次执行的语句、耗时、影响行数 / 错误信息

### 结果表格

- 表头两行：**字段名 + 类型缩写**；主键列带 **PK** 徽标；第二行显示字段的 **COMMENT 描述**（来自 `information_schema.COLUMNS`）
- 单元格内容过长自动截断，点击单元格可查看 / 复制完整内容
- **单元格右键菜单**：复制单元格值，或按当前行数据生成 SQL——「复制为 INSERT 语句」「复制为 UPDATE 语句」（可直接粘贴到编辑器执行）
- 底部信息条固定显示：**行数 · 耗时**，不随内容滚动
- 「下载 CSV」可将当前结果集导出为 CSV

### 调整高度

拖动编辑器与结果区之间的**分隔条**可调整结果区高度（双击场景：结果区默认约 45% 视口高）。

## 5. SQL 脚本

把常用 SQL 保存为脚本，避免重复粘贴。

- **保存**：**⌘/Ctrl + S** 或工具条「保存脚本」→ 输入脚本名称（首次保存需命名）
- **更新**：已保存过的脚本再次 ⌘/Ctrl + S 时，可选择「更新当前脚本」或「另存为新脚本」；修改未保存时标签名旁有 **●** 提示
- **重命名**：在左下角「脚本」面板中双击脚本名
- **打开**：点击脚本即在新查询标签页载入；可删除脚本

> 脚本全部保存在本机（Web 模式 localStorage / 插件模式 chrome.storage），仅本机本浏览器可见。

## 6. 执行历史

左下角「**历史**」面板自动记录最近执行的 SQL（含连接、Schema、耗时、成功 / 失败状态）。点击任意一条即可在新查询标签页中回填重跑。

## 7. 导出

### 导出 SQL（表右键「导出 SQL（DDL + 数据）…」）

导出弹窗内可勾选：

| 选项 | 说明 |
| --- | --- |
| 包含 DDL | 输出 `SHOW CREATE TABLE` 的建表语句 |
| 前置 `DROP TABLE IF EXISTS` | 建表语句前加删表语句 |
| 包含数据 INSERT | 输出表数据（SELECT 全字段），上限 **50000 行**，超出会在标题下方提示 |
| `INSERT IGNORE` | 数据语句改写为 `INSERT IGNORE`，导入时跳过冲突行 |

底部按钮：

- **下载 CSV**：导出表数据 CSV
- **下载 SQL**：按当前选项生成 `.sql` 文件并**直接下载**
- **SQL预览**：打开预览弹窗（语法高亮），可复制全文或下载 `.sql`；预览**叠加**在导出弹窗上层，关闭预览后导出弹窗原样保留，可继续调整选项后再次预览或下载

### 查询结果导出

结果表格工具条的「下载 CSV」直接导出当前结果集。

### DDL 查看

表右键「查看 DDL」的弹窗同样支持复制与下载 `.ddl.sql`。

## 8. 界面与个性化

- **主题**：顶栏**调色板按钮**弹出主题菜单，内置 9 套主流配色，菜单项带三色色卡预览（背景 / 强调 / 关键字），当前主题标 ✓：
  - **暗色**：默认暗色（GitHub Dark 风）/ One Dark Pro / Dracula / Tokyo Night / Monokai / Nord
  - **亮色**：默认亮色 / GitHub Light / Solarized Light
  - 选择即生效并持久化；刷新页面无闪烁（首帧前即恢复上次主题）
- **左侧面板**：底部「脚本 / 历史」面板可通过页签栏右侧的 **⌄ / ⌃** 收起或展开，状态持久化
- **数据安全**：所有数据（连接、标签页、脚本、历史、偏好）仅保存在本机（Web 模式 `localStorage` / 插件模式 `chrome.storage.local`），**不经过任何第三方服务器**；清除浏览器数据或卸载插件会一并清除

## 10. Chrome 插件模式

除 Web 方式外，本项目可打包为 **Chrome 插件（MV3）** 安装使用，功能与 Web 模式完全一致，数据跟随浏览器 Profile 保存。

### 构建与安装

```bash
npm run build:ext   # 构建产物输出到 dist/（静态前端 + manifest.json + sw.js）
```

1. 打开 Chrome，访问 `chrome://extensions`
2. 打开右上角「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」，选择项目的 `dist/` 目录
4. 安装后点击工具栏中的插件图标，即在全屏标签页中打开客户端

### 启动桥接器

插件产物是纯静态前端（浏览器无法直连 MySQL TCP），需要单独运行本机桥接器：

```bash
npm run bridge   # 默认监听 5189 端口，可通过 MYSQL_BRIDGE_PORT 环境变量或命令行参数修改
```

插件模式下的连接，桥接地址留空即自动连接 `ws://localhost:5189/__mysql_bridge`；若自建了桥接服务，可在「高级选项」中手动填写（公网地址必须使用 `wss://`）。

### 与 Web 模式的差异

| 项 | Web 模式 | Chrome 插件模式 |
| --- | --- | --- |
| 打开方式 | `npm run dev` 启动的网页 | 工具栏插件图标（全屏标签页） |
| 桥接器 | 内嵌在 Vite dev server（与页面同端口） | 独立进程 `npm run bridge`（默认 5189） |
| 数据存储 | `localStorage` | `chrome.storage.local` |
| 连接 MySQL | 由 dev server 内嵌桥接器代理 | 由本机独立桥接器代理 |

> 卸载插件会清除 `chrome.storage.local` 中的全部数据（连接、脚本、历史等），重要脚本请提前导出备份。

## 11. 常见问题 FAQ

**Q1：提示「WebSocket 桥接连接失败」？**
A：说明页面连不上内置桥接器。确认 dev server 正在运行（`npm run dev`）；若手动填过桥接地址，请清空「高级选项」中的桥接地址让其自动生成。

**Q2：提示 `Access denied ... (using password: NO)`？**
A：密码没有随连接发送。编辑该连接，确认密码已填写；未勾选「记住密码」时，刷新页面后需重新输入密码。

**Q3：提示认证插件不支持（如 `caching_sha2_password` 报错）？**
A：桥接器基于 mysql2，支持 MySQL 8 默认的 `caching_sha2_password`。若使用 `sha256_password` 或开启了特殊 SSL 策略，请检查服务端认证配置。

**Q4：连接超时？**
A：确认 MySQL 服务器地址 / 端口正确、网络可达；云数据库请检查 IP 白名单是否放行了**你本机的公网出口 IP**（不是浏览器 IP，是运行 dev server 的机器的出口 IP）。

**Q5：结果表头没有显示 COMMENT？**
A：COMMENT 通过 `information_schema.COLUMNS` 补齐获取；若连接账号无权限读取 `information_schema`，注释列为空但不影响结果。

**Q6：导出的 INSERT 只有 50000 行？**
A：数据导出设有安全上限（防止超大表拖垮浏览器），达到上限时会在导出弹窗标题下提示「已达导出上限」。超大表建议使用 `mysqldump` 等专业工具。

**Q7：刷新后连接还在但密码没了？**
A：未勾选「记住密码」的连接只保留连接信息，密码按设计不落盘，重新输入即可。

**Q8：可以部署到服务器给团队用吗？**
A：`npm run build` 的产物是纯静态前端，不含桥接器，直接部署**无法连库**。团队使用需要自行实现带鉴权的独立桥接服务，并在「高级选项」中填写其地址。详见 [架构说明](architecture.md)。

**Q9：插件模式下提示「WebSocket 桥接连接失败」？**
A：确认已在终端运行 `npm run bridge` 启动独立桥接器（默认端口 5189，可用 `curl http://127.0.0.1:5189/` 做健康检查）；若手动填过桥接地址，请清空「高级选项」让其自动生成；远程桥接必须使用 `wss://` 地址。
