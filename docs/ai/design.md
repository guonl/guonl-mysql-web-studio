# AI 助手 · 交互与 UI 设计

遵循产品「同构」原则：所有颜色、圆角、字体走 `src/styles/global.css` 的既有 CSS 变量，9 套主题零适配；组件形态与现有 Sidebar / Modal / ContextMenu 保持同一家族感。

---

## 1. 信息架构与布局

AI 面板是 `.main` 内的**第三列**（与左侧栏对称，挤压中间 Workbench 而非浮层遮挡）：

```
┌────────────────────────────────────────────────────────────────┐
│ Topbar   [MySQL Web Studio]              …  [✨AI]  [🎨] [GitHub]│
├──────────┬───────────────────────────────────┬─────────────────┤
│ Sidebar  │  Workbench（编辑器 / 结果）        │ AI Panel (380px)│
│ (可折叠) │                                    │ ┌─────────────┐ │
│          │                                    │ │ ✨ AI 助手   │ │
│ 连接树    │                                    │ │ gpt-4o ⚙ ✕ │ │
│          │                                    │ ├─────────────┤ │
│          │                                    │ │ 消息流       │ │
│          │                                    │ │  [用户气泡]  │ │
│          │                                    │ │  [AI 卡片]   │ │
│          │                                    │ │  [工具卡片▸] │ │
│          │                                    │ ├─────────────┤ │
│          │                                    │ │ /快捷指令条  │ │
│          │                                    │ │ [输入框][➤] │ │
├──────────┴───────────────────────────────────┴─────────────────┤
│ StatusBar                                                       │
└────────────────────────────────────────────────────────────────┘
```

- 面板宽度可拖拽（260–520px），持久化到 `prefs.aiPanelWidth`；
- 收起时整列消失，Topbar 的 ✨ 按钮重新打开；
- **关闭面板不中断流式请求**，重开后恢复渲染（流式状态在 store，与视图生命周期解耦）。

## 2. 入口按钮（AiFab）

- 位置：Topbar 右侧图标组最左（主题按钮之前）；
- 形态：36×36 图标按钮，Sparkles 图标，强调色描边；
- 动效（尊重 `prefs.aiReduceMotion`）：
  - 呼吸：`box-shadow` 强调色光晕，`2.4s ease-in-out infinite`，幅度 8px→16px；
  - 流式进行中切换为三点跳动角标（右下角小圆点）；
  - 等待确认时角标变为琥珀色感叹号。
- Tooltip：未配置时「接入 AI 助手」；已配置时「AI 助手 · <模型名>」。

## 3. 对话面板（AiPanel）规格

### 3.1 头部（高 40px）

```
[✨ AI 助手]  [模型名 pill]            [🧹 清空] [⚙ 设置] [✕ 关闭]
```

- 模型名 pill：点击 = 快捷切换配置（M3 前仅展示）；
- 清空 = 清空当前会话（二次确认 toast 级）；设置 = 打开模型配置弹窗。

### 3.2 消息流（flex-1 滚动区）

四类消息卡片：

| 类型 | 形态 | 说明 |
| --- | --- | --- |
| user | 右对齐，强调色 10% 底、圆角 10、最大宽 88% | `@表名` 高亮为 pill |
| assistant | 左对齐，透明底 + 左侧 2px 强调色竖线 | Markdown 渲染；流式时尾部光标闪烁 |
| tool | 左对齐，折叠条卡片（`text-3` 色，`border-1` 描边） | 「🔍 已查看 orders 表结构 ▸」；展开显示参数与结果摘要（JSON/DDL 只读块，限高 200px） |
| notice | 居中细条（警告色/错误色） | 错误重试条、预算到达提示、「用户拒绝了执行」 |

**SQL 代码块工具条**（右上角悬浮，三枚小按钮）：

```
┌ sql ──────────────────────── [复制] [⤓ 插入] [▶ 运行] ┐
│ SELECT u.name, COUNT(o.id)                            │
│ FROM users u LEFT JOIN orders o ON ...                │
└───────────────────────────────────────────────────────┘
```

- 插入：写活动标签页编辑器（编辑器桥接见 tech.md），光标落尾部并标脏；
- 运行：复用手动执行的完整通道（结果进结果区页签），等同用户亲自执行；
- 代码块左上角显示语言标签，非 `sql` 代码块只有复制。

### 3.3 输入区（底部，高约 96px）

- 多行 textarea（高 22–88px 自适应），`Enter` 发送 / `Shift+Enter` 换行；
- 发送按钮：空闲 ➤；流式中变为 ■ 停止；
- 快捷指令条：聚焦时输入 `/` 弹出指令菜单（`/explain` `/optimize` `/fix` `/ddl`），↑↓ 选择、Tab/Enter 补全；`/explain` 与 `/fix` 自动携带编辑器选中 SQL / 最近错误；
- 上下文指示：输入框上方一行 10px 小字「上下文：conn-name · schema · 42 张表」，让用户知道模型看到了什么；
- `@` 触发表名补全（取当前 Schema 表清单），选中后发送时附带该表 DDL。

### 3.4 状态与空态

| 状态 | 呈现 |
| --- | --- |
| 未配置 | 欢迎页：✨ 大图标 + 三句话能力介绍 + [配置模型] 主按钮 |
| 无活动连接 | 首条 AI 回复前插 notice：「当前没有已连接的数据库，AI 无法查询真实结构，可先连接或继续纯对话」 |
| 流式中 | 消息尾部光标 + 发送按钮变 ■；顶部细进度条（强调色，indeterminate） |
| 请求失败 | 消息内嵌错误条：错误描述 + [重试] 按钮（重新发送同参数请求） |
| 预算到达 | notice：「已达单次任务工具调用上限（12），请基于以上信息继续或开新话题」 |

## 4. 执行确认弹窗（ConfirmExecModal）

复用现有 Modal 骨架（自动获得弹窗栈能力，可叠加在任意界面之上）：

```
┌ ⚠ 执行确认 ────────────────────────────────┐
│  AI 请求在 [conn-name / schema] 执行：        │
│  ┌ 高风险 · UPDATE 无 WHERE ──────────────┐ │  ← 徽章行：等级色底
│  │ UPDATE users SET status = 1;           │ │  ← SqlViewer 高亮
│  └────────────────────────────────────────┘ │
│  影响范围：整表更新，无法自动回滚               │
│  ☐ 本会话内允许执行相同语句（默认关）           │
│                 [拒绝]  [执行一次]            │
└──────────────────────────────────────────────┘
```

- 风险徽章四档配色：L0 只读=中性灰、L1 数据变更=琥珀、L2 结构变更=橙红、L3 服务器级=红 + 「极高风险」字样；
- 命中 FR-20 特征时徽章行并列特征标签（如「多语句」「无 WHERE」「OUTFILE」）；
- 「执行一次」按钮在 L2/L3 时为红底；L0 且策略=确认时为普通主色；
- 「本会话内允许」仅对完全相同的规范化 SQL 生效，且 L3 永不显示该选项；
- 拒绝 = 返回结果给模型「用户已拒绝执行该语句，请基于此调整建议」，不产生任何副作用；
- 弹窗期间 Agent 循环挂起（Promise 等待），关闭面板/清空会话会自动拒绝所有待确认项。

## 5. 模型配置弹窗（AiSettingsModal）

- 字段：请求地址（带预设下拉：OpenAI / DeepSeek / Moonshot / 通义千问兼容 / Ollama 本地 / 自定义）、模型 ID、API Key（password 输入，可切换明文）、[测试连接]；
- 测试按钮三态：默认 → 测试中（禁用）→ 结果内联（成功=绿「连接成功 · 模型可用」，失败=红具体原因）；
- 安全策略区：L0 只读自动执行开关（默认开）、Agent 轮次上限（数字）、恢复动效开关；
- 底部隐私声明（`text-3` 小字）：「密钥与对话仅保存在本机浏览器；请求仅发往上述地址；不包含数据库连接密码。」

## 6. 状态机

```
会话状态：idle ──发送──► streaming ──完成/停止/错误──► idle
                              │
                              └─模型发起工具─► tool_running ─┬─自动执行(L0)─► 回填 ─┐
                                                             ├─需确认────► confirming ─确认/拒绝─► 回填 ─┤
                                                             └─工具报错──► 回填错误 ───────────────────┘
                                                             （循环直至 final answer 或预算到达 → idle）
```

面板状态：`closed ⇄ open`（Topbar 按钮 / ✕）；open 下内部仅有一个会话状态机，不引入二级模态流。

## 7. 键盘与可用性

| 按键 | 行为 |
| --- | --- |
| `Enter` / `Shift+Enter` | 发送 / 换行 |
| `Esc` | 关闭指令菜单 → 关闭面板（不中断流式与待确认弹窗——确认弹窗有自己的 Esc=拒绝语义） |
| `↑` / `↓` | 指令菜单导航 |
| `Cmd/Ctrl + ↑` | 跳到最新消息（滚动区外时显示「回到底部」浮标） |

- 所有图标按钮配 `title`；风险徽章不只靠颜色，同时有文字等级（色弱可辨）；
- 面板打开时焦点自动落输入框；流式中输入框保持可编辑（可预输入下一条）。

| 动效时长 | 开合 180ms ease-out、卡片进入 120ms、光标闪烁 800ms |
